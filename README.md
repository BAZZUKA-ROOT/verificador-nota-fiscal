# 🧾 Verificador de Nota Fiscal

Ferramenta web para verificar autenticidade de notas fiscais e cupons de produtos — detecta documentos falsos comparando padrões e campos obrigatórios.

![Language](https://img.shields.io/badge/Stack-HTML%20%7C%20JS-orange) ![License](https://img.shields.io/badge/Licen%C3%A7a-MIT-blue)

## O que faz

- Interface para inserir dados de notas fiscais
- Verifica campos obrigatórios e formatos válidos
- Detecta inconsistências que indicam documentos falsos
- Exibe resultado visual com botões de ação por produto
- Zero dependências — arquivo único, funciona offline

## Como usar

1. Abra `index.html` no navegador
2. Insira os dados da nota/cupom
3. Clique em verificar
